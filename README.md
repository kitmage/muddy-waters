# Muddy Waters — Fan Page

A single-page GitHub Pages tribute to Muddy Waters (McKinley Morganfield, 1913–1983), father of modern Chicago blues.

Includes a detailed original biography, timeline, photo gallery (Wikimedia Commons, credited), essential songs and albums, and listening/video embeds from Spotify and YouTube (no audio hosted).

Live site: https://kitmage.github.io/muddy-waters/
